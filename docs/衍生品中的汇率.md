一步两状态模型：

有一个汇率X = c_2/c_1，它在T1有两种可能， A：1.1 和 B：0.9。 现在，有两个Arrow Security， Sa，Sb。分别在 A和B出现时，在T1支付 1 c_1。这两Arrow Security 在 T0时刻的价值是 Pa 和 Pb c_1。
1) 显然我们有同时持有一份Sa和一份Sb 后，T1在任和情况下都得到 1 c_1。从而 Pa+Pb = 1 。 Pa 和 Pb 形成一个测度。
2) T0持有1.1Sa + 0.9Sb 和 1 c_2, 在T1时的结果是一样的。于是有 T0时，1 c_2 = (1.1Pa + 0.9Pb) c_1 ，这就是鞅定价。

假设 Pa = Pb = 0.5, 有 T0时1 c_2 = 1 c_1。

反过来，再看Sa 和 Sb 在c_2下T0时的价格。应该有 Pa_2 = Pa /x(0), Pb_2 = Pb/x(0)。 这样 Pa_2 = Pb_2 = 0.5。但要注意， 这不是c_2下的Arrow Security，因为支付的是1 c_1而不是c_2。那么对应的支付 1 c_2 的真Arrow 有  Qa = Pa_2 * c_2/c_1 = 0.5*1.1 ; Qb = 0.5* 0.9。 

明显 Q和 P是不一样的，所以没有全局的测度。

整理一下，有对于 X = c_2/c_1。应该有在c_1下

sum {P(X = x_i)} = 1
sum {x_i P(X = x_i)} = X(0) …… (i) x在P下是鞅。

在 c_2下，
Q(X = x_i) = P(X=x_i) * x_i  / X(0)  …… (ii)
sum {Q(X = x_i) } = sum {x_i P(X = x_i)/X(0)} = 1…… (iii) 根据(i)
这证明了Q是测度，(ii)就是测度变换的关系。
sum{ (1/x_i) Q(X=x_i)} = sum{P(X=x_i) /X(0)} = 1/X(0)  ……(iv)。
这证明了 1/x 在Q下是鞅。这个过程是well defined。 


一个mono，其估值应该是 
v = E_p( x * Payoff(s))
   = sum{ P(X = x_i, S = s_j ) * x_i  * Payoff(s_j) }
   = sum{ P(X=x_i) * P(S=s_j |X=x_i) * x_i * Payoff(s_j) }
   = sum{ Q(X=x_i) * X(0) * P(S=s_j |X = x_i) * Payoff(s_j)}
   = X(0) sum


$$
\begin{eqnarray*}
V_p &=& E_p( X f(S)) \\
&=& \sum \limits_{i,j} P(X = x_i, S= s_j) x_i f(s_j) \\
&=& \sum \limits_{i,j} P(X = x_i) x_i P(S=s_j | X=x_i) f(s_j)\\
&=& \sum \limits_{i,j} Q(X = x_i) X(0) P(S=s_j | X=x_i) f(s_j) \\
&=& X(0) \sum \limits_{j} (\sum \limits_{i} Q(X = x_i) P(S=s_j | X=x_i)) f(s_j) \\
\end{eqnarray*}
$$

定义$Q(S= s_j) := \sum \limits_{i} Q(X = x_i) P(S=s_j | X=x_i)$，显然有$\sum \limits_{j}Q(S=s_j) = 1$ 于是有：

$$
\begin{eqnarray*}
V_p &=& X(0) \sum Q(S=s_j)  f(s_j) \\
	&=& X(0) V_q
