还是从鞅定价和对冲两个角度来分析这个问题。本文在不另行说明的时候，用如下的标记惯例：
* 大写：随机变量或者过程；小写：值
* $X$: 汇率；$S$：标的价格
* $f()$: Payoff
* 下标：时间参数
* 上标：$^{\prime}$，强调在外币下的量; 指标集也放上标
* 测度：概率测度

再表述一下三类衍生品。标的都是外币资产
* **compo**: Payoff是依赖于外币资产的价本币价值。$f(s _t*x _t)$。
* **mono**: Payoff的**数值**是依赖于外币资产的外币价格，以外币支付，但是最终会以本币以到期日的汇率结算。$f(s _t)*x _t$。
* **quanto**: Payoff的**数值**是依赖于外币资产的外币**价格**，但是以本币期初的汇率结算。$f(s _t)*x _0$。

可以看到一个特殊的情况，挂期货的compo 
$$
\begin{eqnarray*}
f(s^{futurePrice} _ t*x _ t) := (s^{underlyingPrice} _ t-s^{underlyingPrice} _ 0)*x _ t
\end{eqnarray*}
$$
注意到$s^{underlyingPrice} _ 0$是定值，所以它是一个mono。


直观的感受上，对应的对冲逻辑如下：
* **compo**: $s _t*x _t$ 本身就是本币下的可交易价格，直接是它的衍生品就好了。
* **mono**: 如果完全在外币下，买一个$f(s _t)$的期权，就能完整的对冲。而他在$t=0$的时候是有外币估值$v^{\prime}$的，那本币价值就是$v=v^{\prime} x _0$。
* **quanto**: 说来话长，可以想象并没有一个直接的方式知道方便的持有外汇来对冲这个敞口。

## 鞅定价视角
先要解决汇率的地位的问题。$X = c ^{\prime}/c$，是两个货币单位的比例。让我们关注在$S,X$上，暂时让$r = r ^{\prime} = 0$。

把$X$视为一在本币下的一个价格，同样$1/X$会是在外币下的一个价格。很显然，如果在某一测度下，$X$是鞅，那么$1/X$一定不是。说明，不存在一个全局可用的风险中性测度。那这些测度有什么关系呢？再回到 Arrow Security的语言来，如果 $\mathbb{P}(X = x ^i)$是$t$时刻$X = x ^i$ 的Arrow Security(即支付$1 c$)的价格，有：

1. 考虑持有$1$份所有的 Arrow Security，Payoff是在任何事件下$1 c$，于是有 $\sum \limits _{i}^{} \mathbb{P}(X = x^i) = 1$。所以$\mathbb{P}$形成一个测度。
2. 考虑持有$x ^i$ 份 $X= x ^i$的 Arrow Security，在$t$任何事件下Payoff和持有$1 c ^{\prime}$一样。所以 $\sum \limits _{i}^{} x^i\mathbb{P}(X = x ^i) = x _0$。$X$在$\mathbb{P}$下是鞅。

一切很合理。再转到$c ^{\prime}$下来看。对于同一个事件，$c$ 下的Arrow Security 并不是$c ^{\prime}$下的，因为支付的是$1 c$而不是$1 c ^{\prime}$，后者是前者的$X _t$倍。于是$c ^{\prime}$下的一个$X = x^i$的Arrow Security 在$c$的价格应该是 $\mathbb{P}(X = x ^i) x^i $，从而在 $c ^{\prime}$下价格应该是 $\mathbb{P}(X = x ^i) x^i/x _0 =: \mathbb{P} ^{\prime}(X = x ^i)$。注意到：

1. 根据上面的第2点，有 $\sum \limits _{i}^{}\mathbb{P} ^{\prime}(X = x ^i) = 1$。从而$\mathbb{P}^{\prime}$是测度。
2. 根据上面的第1点，有 $\sum \limits _{i}^{}\mathbb{P} ^{\prime}(X = x ^i) (1/x ^i) = 1/x _0$。从而$1/X$在$\mathbb{P}^{\prime}$下是鞅。

也很合理，一切很well defined。前面我们想要的测度的变换关系就是：
$$
\begin{eqnarray*}
\mathbb{P} ^{\prime}(X = x ^i) = \mathbb{P}(X = x ^i)x^i/x _0 \tag{m-t0}
\end{eqnarray*}
$$
再进一步，我们看看存在外币下标的$S$的情况下，$c$的指向$X = x^i, S = s^j$ 的 Arrow Security。它的价格是 $\mathbb{P}(X = x^i, S = s^j)$，对应的$c ^{\prime}$下的Arrow Security的价格是$P\mathbb{P}^{\prime}(X = x^i, S = s^j)$。其中仍然只差一个换汇，还是有：
$$
\begin{eqnarray*}
\mathbb{P} ^{\prime}(X = x ^i, S= S^j) = \mathbb{P}(X = x ^i, S= S^j)x^i/x _0 \tag{m-t1}
\end{eqnarray*}
$$
引出一个下面我们会用到的结论
$$
\begin{eqnarray*}
\mathbb{P} ^{\prime}(S= S^j \vert X = x ^i) = \mathbb{P} (S= S^j \vert X = x ^i)
\end{eqnarray*}
$$


下面来看定价。

### Compo
$$
\begin{eqnarray*}
V &=& \mathcal{E}_\mathbb{P} (f(S_t*X_t)) \\
\end{eqnarray*}
$$
此时， $O _t = S _t*X _t$ 是一个在$c$计价下的可交易资产，在$\mathbb{P}$下就是鞅，只用在意它的波动率就行。如果在$c$下$X$的波动率是$\sigma _X$，在$c ^{\prime}$下$S$的波动率是$\sigma _S$，有
$$
\begin{eqnarray*}
\sigma _O = \sqrt{\sigma _S^2 + \sigma _X^2 + 2\rho \sigma _X \sigma _S}
\end{eqnarray*}
$$

### Mono

$$
\begin{eqnarray*}
V &=& \mathcal{E}_\mathbb{P} (X_t f(S_t)) \\
&=& \sum \limits_{i,j} \mathbb{P}(X = x^i, S= s^j) x^i f(s^j) \\
&=& \sum \limits_{i,j} [\mathbb{P}(X = x^i) x^i] \mathbb{P}(S=s^j \vert X=x^i) f(s^j)\\
&=& \sum \limits_{i,j} [\mathbb{P}^{\prime} (X = x^i)x_0]\mathbb{P}(S=s^j \vert X=x^i) f(s^j)\\
&=& x_0 \sum \limits_{j} [\sum \limits_{i} \mathbb{P}^{\prime}(X = x^i) \mathbb{P}(S=s^j \vert X=x^i)] f(s^j) \\
\end{eqnarray*}
$$

定义$\mathbb{P}^{\prime} (S= s^j) := \sum \limits_{i} \mathbb{P}^{\prime}(X = x^i) \mathbb{P}(S=s^j \vert X=x^i)$，显然有$\sum \limits_{j}\mathbb{P}^{\prime}(S=s^j) = 1$  是个测度。于是有：

$$
\begin{eqnarray*}
V &=& x_0 \sum \mathbb{P}^{\prime}(S=s^j)  f(s^j) \\
&=& x_0 V ^{\prime}
\end{eqnarray*}
$$

### Quanto
$$
\begin{eqnarray*}
V &=& x_0\mathcal{E}_\mathbb{P} (f(S_t)) \\
\end{eqnarray*}
$$
这个式子看上去非常简单，但恰恰不干净，因为 $S$ 不是在 $c$下的价格，而是$c ^{\prime}$下的。我们通常用于表述$S _t$的过程的方程，也是在$c ^{\prime}$下的价格。$S _t$在$\mathbb{P}$下不是鞅。所以首先需要得到$S _t$在$\mathbb{P}$下的表述。

我们需要把$c ^{\prime}$下的鞅价格换到$c$下。沿用前面的推导，有：
$$
\begin{eqnarray*}
V &=& x_0 \sum \limits_{j}^{} f(s^j) \mathbb{P} (S = s^j) \\
&=& x_0 \sum \limits_{i,j}^{} f(s^j) \mathbb{P}^{\prime} (S = s^j, X = x^i) x_0/x^i\\
\end{eqnarray*}
$$
如果 $X$和$S$ 独立，上式简化为：
$$
\begin{eqnarray*}
V &=& x_0 \sum \limits_{i,j}^{} f(s^j) \mathbb{P}^{\prime} (S = s^j) \mathbb{P}^{\prime}(X = x^i) x_0/x^i\\
&=& x_0 [ \sum \limits_{i}^{} \mathbb{P} (X = X^i) ] \sum \limits_{j}^{} f(s^j)\mathbb{P}^{\prime} (S = s^j) \\
&=& x_0 V ^{\prime}
\end{eqnarray*}
$$
即只需在$c ^{\prime}$下估值即可。而如果两者不独立，我们先定性的看$\mathbb{P}^{\prime} (S = s^j, X = x^i) x _0/x^i$。假设$S,X$正相关，那么在$S$上涨时，$X$有更大的概率是上涨的，也就是 $1/X$更小，有$\mathcal(E) _{\mathbb{P}} X _t < x _0$，即这个过程是向下漂移的。经过和 **Ito Lemma** 类似的推导，可知：
$$
\begin{eqnarray*}
\sigma_s^2 \mathrm{d} W_{\mathbb{P}^{\prime}} \Rightarrow \sigma_s^2 \mathrm{d} W_{\mathbb{P}} - \rho(S,X) \sigma_s \sigma_x
\end{eqnarray*}
$$
通过这个式子来驱动$c$下的随机过程，再求期望就好。


## 对冲视角
其实值得说的只有Quanto。Compo就是个波动性“叠加”的资产，逐点换汇对冲就行；Mono就更简单了，只用在外币融资买入期权 or 动态对冲，最后换汇回本币就行。而Quanto：
* 取$X$是常数的极端，很显然，需要通过持有$S$来动态对冲。
* 取$S$是常数的极端，会比较奇怪。发现并不需要持有$X$来动态对冲，这一点容易让人困惑：完全没有汇率什么事吗？对冲时买卖外币资产的现金收入，不需要对冲其汇率风险？嘿，前面的公式还真告诉我们是这样。直观的感受一下吧：如何对冲当前notional为$1 c$的一个线性的Quanto？
  * 很显然，在开始的这一瞬间，我们需要持有 $1/x _0 c ^{\prime}$的$S$。
  * 一开始也许会觉得，如果$S$上涨一倍，期权上我们需要支付$1 c$，而对冲端我们能得到 $ 1/x _0 c^{\prime}$，而如果不对冲汇率风险，期权和对冲的Payoff是不匹配的。
  * 然而，不是的不是的。实际的对冲过程几乎会是这样的，我们不会固定的持有$1/x _0 c ^{\prime}$的$S$，当市场变到$s _t,x _t$的时候，我们需要持有大约 $s _t /(s _0 x _t) c ^{\prime}$的$S$。
  * 回看每一个瞬间，如果$X$不含布朗运动项，总可以取到小的时间段$\Delta t$。使得$X$的变化相对$S$的变化很小，那么只要通过$s _t /(s _0 x _t) c ^{\prime}$的对冲，可以使这段时间的合并盈亏相对$\Delta t$忽略不计。这就能完美的对冲。
  * 如果$X$含布朗运动项，当对冲端得到 $s _t /(s _0 x _t) c ^{\prime}$的盈亏时，已经不能按$x _t$换成$c$了。于是出现了“相关性”的项。
  * 接下来的问题是：“哦，我明白了，在平均的意义上，$X,S$的正相关是会有负的影响的，可为什么对应的是漂移。而且你不是要求在任意路径上都成立而不是平均的结果吗？” 答案其实很直接：多元布朗运动的**二次协变**，有结论:$[W^1,W^2] _t = \rho t$(a.s.)。正比于$t$说明是漂移，“a.s.”说明任意路径上都对。
* 为什么说Quanto不好，原因在于对二次变差和二次协变的估计的可靠性差别很大。
  * 首先，二次变差只能是正的，二次协变还能是负的。
  * 其次，二次协变除了波动性，还依赖于相关性。其中波动性依赖一些相对稳定的基础：信息的产生速度、交易的方式、参与者的分布。但相关性的依赖基础更加的不确定。
